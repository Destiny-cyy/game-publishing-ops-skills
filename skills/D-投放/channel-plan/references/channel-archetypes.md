## A · {{CHANNEL_TYPE_A}} / 工具类（转化基础设施）

**角色**：不是媒体位，是**转化链路本身**。{{SERVER_LINE_A}}最大门槛是网络与入库，"一键入库 + 加速"就是转化。

| 维度 | 内容 |
|---|---|
| 目标 | 参与人数、加速人数环比、入库任务完成率、曝光率（+回归人数；**预约期 + 预约页跳转**） |
| 内容形式 | 客户端 banner / 弹窗 / 加速页活动 / 补给站页 / Push / 活动中心 |
| 触达方式 | 端内自有资源位，用户已在"要玩外服游戏"的场景里 |
| 合作与成本 | **资源置换，零采买**，只花奖励费与奖品费 |
| 节奏 | **与版本上线日同步开跑**，活动期 {{BASELINE_VALUE}}天（默认版本日 → 版本日+7）；可跨预热-爆发 |
| 主口径 | **参与人数（不去重）/ 加速人数环比（%）/ 入库任务完成率 / 曝光率** |
| 参考指标 | 资源位曝光、banner 点击、活动页 UV、加速时长、抽奖人次（均不可跨渠道相加） |
| 适配策略 | 任务链必须落到**入库 + 加速**动作；**用足加速福利**（渠道自有、零成本、对用户真价值）；回归任务单独设档（对应 L1 回流，效率最高） |

⚠️ **口径变更（{{AS_OF_DATE}}）**：原「入库人数」取消——**{{CHANNEL_TYPE_A}}侧统计不到 平台入库结果**（入库发生在 {{PLATFORM_A}} 侧、数据不回传渠道），渠道只能给页面点击数据，故改测 **入库任务完成率**（完成入库任务人数 ÷ 参与人数）——「页面点击率」因分母不可比、可被按钮位置操纵，现已废弃。加速绝对数各家口径不一，改报**环比百分比**。参与人数**不要求去重**（{{CHANNEL_C}} 只报人次，其余各家去重能力不一）。新增**曝光率**做履约验收。

⚠️ **两个历史硬基线**：① 回归任务完成数长期只有 {{BASELINE_VALUE}}（唯一例外 3,{{BASELINE_VALUE}}，那期做了独立入口）→ 回归任务必须有独立入口 + 定向触达；② 入库数波动 {{BASELINE_VALUE}}，取决于「一键入库」是否首屏前置 → 强制放首屏第一格。

**常见坑**
- 只写"banner 曝光 XX 万"当成果——浪费了转化能力
- 不用加速福利（渠道白给的资源，不用白不用）
- {{CHANNEL_COUNT}}家活动形式写成同一段（{{CHANNEL_D}}无"关注"任务、{{CHANNEL_B}}/{{CHANNEL_A}} 有关注任务，任务链不同）

**话术差异示例**
- {{CHANNEL_D}}：入库 + 首次加速 + 加速达 15/60 分钟 → 抽奖机会 & 加速福利
- {{CHANNEL_B}}/{{CHANNEL_A}}：关注社媒 + 入库 + 游玩（加速）达时长 → 抽奖机会 & 加速福利
- {{CHANNEL_C}}：PC+移动双端资源 + UP 主植入，另走 KOL 包

## B · 游戏社区 & 商城（转化 + 内容双担）

**角色**：唯一同时具备"内容场"和"分发能力"的一类。能一键入库、能跑 CPS、能发 KOC。

| 维度 | 内容 |
|---|---|
| 目标 | 入库人数、CPS 销量、活动参与人数、社区话题量（⚠️ **"入库人数"只有这一类渠道能报**——它有 CPS 与一键入库能力，数据回传得回来；**{{CHANNEL_TYPE_A}}{{CHANNEL_COUNT}}家报不了，不准写这个指标**，见下方"口径变更"） |
| 内容形式 | H5 活动页 / 社区话题与活动合集 / KOC 资讯 / 商城 CDK 分销 |
| 触达方式 | APP 内热点 banner、活动页、信息流、话题页 |
| 合作与成本 | **采买为主 + CPS + 社区合作**；使用方项目单渠道采买最大头（{{BASELINE_VALUE}} + 奖励 {{BASELINE_VALUE}}） |
| 节奏 | **周期最长**，可跨预热到爆发（11/{{BASELINE_VALUE}}/22 这类长周期是常态） |
| 主口径 | 入库人数 / CPS 销量 / 活动参与人数 |
| 参考指标 | 曝光、点击、点赞收藏评论、KOC 篇均阅读 |
| 适配策略 | H5 积分制（关注/入库/分享 → 积分 → 兑奖）；社区话题做 UGC 沉淀；KOC 做长尾口碑 |

## C · 垂直媒体（声量与口碑）

**角色**：做话题、做口碑、做搜索沉淀。**不是效果渠道**。

| 维度 | 内容 |
|---|---|
| 目标 | 互动量、预约人数、阅读/播放量、正面声量占比 |
| 内容形式 | 论坛有奖互动（评论 / 点赞 / 晒图）、资讯稿、话题征集 |
| 触达方式 | 门户站内、论坛版块、编辑推荐位 |
| 合作与成本 | **资源采买**（{{MEDIA_CHANNEL}} {{BASELINE_VALUE}}、{{MEDIA_CHANNEL}} {{BASELINE_VALUE}}、旅法师 {{BASELINE_VALUE}}）或置换（{{MEDIA_CHANNEL}}） |
| 节奏 | **短频快**，一波一个话题；预热段做期待，爆发段做口碑 |
| 主口径 | 互动量（评论+点赞）/ 预约人数 / 阅读量 |
| 参考指标 | 曝光、参与人数、负面声量占比 |
| 适配策略 | 话题必须具体到可讨论（"聊新版本内容""晒预约截图"），不要"说说你的看法"；奖品走轻量（平台充值卡/周边），重参与广度不重深度 |

- {{MEDIA_CHANNEL}}：单波论坛活动预估参与 {{BASELINE_VALUE}}人量级，预约 {{BASELINE_VALUE}}
- {{MEDIA_CHANNEL}}：采买 {{BASELINE_VALUE}}万/波，参与预估 {{BASELINE_VALUE}}
- 旅法师营地：预估参与 {{BASELINE_VALUE}}
- {{MEDIA_CHANNEL}} APP：{{VERSION_NAME_HIST}} 三活动曝光 {{BASELINE_VALUE}} / {{BASELINE_VALUE}} / {{BASELINE_VALUE}}；支持预约 H5 内嵌、可圈定 平台玩家定投

**常见坑**
- 用 CTR / CPA 考核它 → 逼出标题党，伤口碑

## F · 网吧与内渠（场景铺量）

**角色**：长尾常驻的场景入口，胜在覆盖，不追求单点的深度转化。

| 维度 | 内容 |
|---|---|
| 目标 | 启动量、CPS 销量、曝光覆盖 |
| 内容形式 | 客户端位、壁纸软件、网吧活动物料、特权奖励 |
| 触达方式 | 网吧终端开机/启动场景、安全软件内游戏位 |
| 合作与成本 | CPS 或资源采买；内渠多为**免费上架或置换** |
| 节奏 | **长尾常驻**，不追版本爆发点 |
| 主口径 | 启动量 / CPS 销量 |
| 参考指标 | 覆盖门店数、曝光 |
| 适配策略 | 用"常驻 + 节点换素材"维持；不指望它扛爆发期 KPI |

## G · 私域 / 社区（留存与回流）

**角色**：留存与回流，是唯一能反复触达且边际成本趋零的渠道。

| 维度 | 内容 |
|---|---|
| 目标 | 活跃度、回流率、内容产出量 |
| 内容形式 | 社群运营、公会活动、官号互动、UGC 征集、野生群渗透 |
| 触达方式 | {{COMMUNITY_FORUM}}、公会、{{COMMUNITY_VIDEO}}/{{MEDIA_CHANNEL}}/{{MEDIA_CHANNEL}}官号 |
| 合作与成本 | **人力为主**，几乎无采买成本 |
| 节奏 | 日常持续，节点加码 |
| 主口径 | 活跃人数 / 回流人数 / 内容产出量 |
| 参考指标 | 消息量、互动量 |
| 适配策略 | **先参与后发声**——先以玩家身份在社区里存在，再发官方内容；节点期做 UGC 征集把内容生产外包给玩家 |

**常见坑**
- 直接发官方通稿（该社区对官方腔极度敏感，红线 2）
- 外团渗透野生群不走立项流程（约束 5）
- 把私域当拉新渠道用（它是留存与回流）

## 一句话总结差异

| 原型 | 你要它给你什么 | 你别指望它给你什么 |
|---|---|---|
| A {{CHANNEL_TYPE_A}} | 入库 + 加速（转化本身） | 声量与内容沉淀 |

| C 垂媒 | 话题与口碑 | 转化与 ROI |
| D 平台位 | 平台内发现与预约 | 自主控节奏 |
| E 信息流 | 规模化买量与 ROI | 口碑与社区资产 |
| F 网吧内渠 | 长尾覆盖 | 爆发期 KPI |
| G 私域社区 | 留存与回流 | 拉新规模 |
