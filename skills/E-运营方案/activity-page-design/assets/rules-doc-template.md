## 模板使用说明（落稿时删除）

1. **先建资料地图再写本文档**：按 `../references/material-integration.md`，登记元信息、按需取用、每步留痕。本文档的 对应章节 / §16 就是留痕落点。
2. **「留 / 移 / 拆」三动作**：框架版里的一手摘录留 §2；约束与论证移入对应节；混在方案正文的规则拆出来。**方案之外全归它**。
3. **纯方案正文校验**：不得出现「待确认 / 出处 / 验收 / DDL / 内部资料 / 工具调研 / @人」；反向检查本文档有没有把结论态正文抄进来。
4. **逐轮收口固定四件事**：本轮表述优化记录（对应章节）＋ 新增验收节（对应章节x）＋ 红线 / 词表 / 待确认同步；**回头扫 `references/` 与 `assets/` 模板（含写死项）把本轮新决策写进 skill**；再联合自检；再追加当日 memory。
5. **带时点历史行保留不改写**；数字计数**改指针不改数**；失效行号 / 重复待确认 / 已绕开的译名冲突按留痕分类表 C 类修正，见 `../references/acceptance.md`。历次迭代若补录，按 A 类**带时点追加**，不改写既有行。
6. **本线不并入渠道准则**：与 `_shared/REDLINES.md` 互不引用、互不并入；只借「事实→口径→目标→活动→奖品→排期」方法论。
7. 改完本文档 → **回头扫本 skill 全部 `references/` 与 `assets/` 模板**（模板里的写死项照样误导）→ 更新 `../SKILL.md` 指针表。**未点头的结构性提案登记「待定」，不写成现行规定、不画进模板；已确认后执行的提案按当期真源更新，不留过期断言。**
