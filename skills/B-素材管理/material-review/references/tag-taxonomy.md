## 判定标准

### 画风（单选）

| 取值 | 判定标准 |
| --- | --- |
| 暗黑写实CG | 暗色调、写实人物渲染、哥特/恐怖氛围 |
| 写实风 | 非暗黑调的写实渲染（光线明亮/中性） |
| 手绘概念原画 | 油画感 / 水彩感概念艺术 |
| 平面撞色风 | 高饱和平面化撞色插画 |
| 彩绘玻璃风 | 教堂彩窗质感的插画 |
| 国风 | 中国风 / 水墨 / 国风插画 |
| 装备UI展示 | 以装备/道具卡片为主体、深色 UI 底 |
| 卡通萌系 | Q版吉祥物、可爱贴纸风 |

### 画面元素（多选，最多 3 个）

| 取值 | 判定标准 |
| --- | --- |
| 单角色立绘 | 画面主体为一名角色 |
| 多角色拼条 | 多个角色分格/并排展示 |
| 角色战斗 | 角色与怪物交战的动态场面 |
| BOSS怪物 | 单体大型怪物/首领 |
| 场景风景 | 以场景为主、无角色或角色很小 |
| 游戏内地图 | 地图/界面类截图 |
| 装备道具 | 武器、护甲、道具卡片等 |
| 萌系吉祥物 | Q版宠物/吉祥物 |
| 大字文案 | 画面上有醒目的大号文字 |
| 实机 | 游戏内实机截图画面 |

### 福利呈现（单选）

| 取值 | 判定标准 |
| --- | --- |
| 堆叠式 | 一堆道具/外观密集堆叠在角色脚下或画面底部 |
| 独立圈圈式 | 多个圆形图标框各自独立排布 |
| 单品聚焦 | 1-2 件装备/道具放大特写 |
| 大字福利文案 | 画面有醒目福利文字（如"8元赛季手册优惠"） |
| 无福利 | 纯角色/场景，无奖励道具元素 |

> 边界处理：方形道具卡片排布统一归入「独立圈圈式」；实物奖品（键盘/显卡/手机）与游戏内道具混排统一归「堆叠式」；把握不足时标"中"进复核清单。

### 节点（单选）

| 取值 | 判定口径 |
| --- | --- |
| 周年庆 | 标题/描述含"周年"，或落在周年庆档期 |
| 050档期 | 版本 0.5.0 档期（历史约 9/4-9/17） |
| 040档期 | 版本 0.4.0 档期（历史约 3/15-6/28） |
| 日常 | 其余 |

> ⚠️ 档期日期为推断值，**每次执行需向业务确认**后重算。

### 用户分层

沿用平台后台人群定向口径：新进投放 / 号码包投放 / 老用户投放 / 标签投放。

### 打标置信度

高 = 明确可判；中 = 部分推断（进复核清单）；低 = 只能通用描述。

## 体系演进记录

> ⚠️ 本节仅供执行时理解"为什么这么分"，**不要写进任何交付文档**。对外/对业务方的文档只呈现现行口径，不留版本号与修订史（见 `doc-sync.md`）。

- 初版（AI 打标）：画风 5 类（含「特殊插画风」）、元素 8 类

  - 从「暗黑写实CG」拆出「写实风」
  - 从「手绘概念原画」拆出「平面撞色风」「国风」
  - 元素新增「实机」「游戏内地图」
  - 本次修订：画风 35 条、元素 30 条、福利 1 条

## 扩展原则

新增类别时先问四件事：是否与现有类别互斥？是否只看画面就能判？设计师能否据此执行？拆分后每组样本是否仍 ≥20 条？任一不满足就不要拆。
