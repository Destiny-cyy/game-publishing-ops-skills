# 分析口径与结论写法


> **本文件用到的占位符**（每个该填哪类信息、能不能外发，详见 `01-占位符字典.md`）
>
> | 占位符 | 该填哪类信息 |
> |---|---|
> | `{{GAME_CN}}` | 文本 · 游戏**中文官方全名**，不含版本号 |
> | `{{PLATFORM_A}}` | 文本 · 主投放平台名 |
> | `{{SAMPLE_RECORDS}}` | 整数 · 投放记录**行数** |
> | `{{SAMPLE_UNIQUE_IMAGES}}` | 整数 · 去重后的**唯一创意图**张数 |
> | `{{TABLE_TOOL}}` | 文本 · 你团队用的**在线表格工具** |

## 核心指标

- **CTR 一律曝光加权**：`SUM(点击UV) / SUM(曝光UV)`，禁止对各行 CTR 取简单平均
- 每个结论必须带三个数：**样本量 / 曝光量 / CTR**，缺一不可
- 样本量 < 20 的组别标注"样本不足"，只给方向性结论

## 六个分析维度

| 维度 | 做法 | 常见结论形态 |
| --- | --- | --- |
| 整体 | 按月聚合曝光、点击、CTR；看趋势与 Top/Bottom 素材（曝光 > 50w 才排序） | 月度 CTR 走势、标杆素材 |
| 节点 | 按 040 / 050 / 周年庆 / 日常 分组 | 版本档期是否引爆 CTR |
| 用户分层 | 按新进/号码包/老用户/标签分组 | 各人群效率倍数 |
| 画风 | 画风分组 | 哪种美术风格更吸睛 |
| 画面元素 | 多选字段用 `LIKE "%元素%"` 逐项统计（注意口径重叠，需说明） | 单角色 vs 多角色 |
| 福利呈现 | 福利形式分组 + 画风×福利交叉 | 福利呈现是否为第一杠杆 |

## 第七维度：素材复用与衰减

**为什么单列**：投放记录 ≠ 创意图。一张图会被多条记录复用（不同人群/日期/广告位），只看"记录维度 CTR"会掩盖"老图反复投还有没有用"这个问题。

**做法**（`scripts/reuse_map.py`）：

1. 按**图片链接**把投放记录去重成唯一图，一条记录 = 一次复用
2. 每张图合并算加权 CTR、总曝光，并按复用次数分档（1 / 2 / 3 / 4+）
3. 看两件事：
   - **衰减曲线**：各档的 CTR **中位数**是否随复用次数下降
   - **曝光结构是否倒挂**：低效率档（复用多）是否反而吃掉了大部分曝光

**方法示例（数值请填自己的实测）**：复用次数越多、单图效率通常越低；但「只用 1 次的新图」曝光量小，别把「效率高」和「总量大」混为一谈。填 `{{BASELINE_VALUE}}` 时须带统计区间与证据等级。

**结论写法**：复用控制在 N 次以内 + 缺口应补在新图上，而不是反复复用老图。样本 < 10 张的档位标注"样本极小，仅参考"。

> 复用分档只是相关性，不是因果：也可能是"好图才被复用多次，但投到后面人群疲了"。下结论时留这个余地。

## 大盘 Benchmark 做法

1. 取 {{PLATFORM_A}} 大盘表，按「游戏名 × 月份」聚合曝光与点击
2. 算各游戏曝光加权 CTR，降序排名
3. 定位 {{GAME_CN}} 的名次与分位（如 5/112 = 前 5%）
4. 同时给出当月**中位数**与 **top 25% 线**，判断自身所处水位

### 四个必踩的坑

| 坑 | 后果 / 处理 |
| --- | --- |
| **游戏名变体** | {{GAME_CN}} 在大盘表有两个名字「{{GAME_CN}}」「{{GAME_CN}}」，不合并会算出某月 CTR=0 的假结果。**先 `GROUP BY 游戏名` 看全部变体再合并** |
| **大盘表月份覆盖不全** | 大盘表可能只覆盖近 4 个月，无法对比 1-6 月。报告的对比区间必须按大盘表实际范围写 |
| **只看游戏级会误判** | 游戏级（曝光加权）与素材级（单张 CTR 中位）结论可能**相反**：{{GAME_CN}} 游戏级 82 分位很好看，素材级中位只在大盘 36 分位。**两个口径必须都算**，后者才是真瓶颈 |
| **分位算不出来** | SQL 不支持窗口函数，`SUM(CASE WHEN 点击率<x)` 全返回 null。改为拉明细（设曝光门槛，如 ≥10 万）到本地算分位 |

**参评门槛**：游戏级按"当月曝光 ≥500 万"，素材级按"单张曝光 ≥10 万"，避免小样本刷榜。**同时给出分位与中位对比**，不要只给排名。

## 口径声明模板（交付物开头必备）

每个报告/文档开头写清三件事，避免业务方按错误口径理解：

```
口径：<唯一创意图 N 张 / 投放记录 M 条，二者关系说明>
区间：数据覆盖 YYYY-MM-DD ~ YYYY-MM-DD（若大盘数据区间不同，单独注明）
来源：{{TABLE_TOOL}}「XXX → 子表名」，原表只读未改动
```

> 真实教训：业务方曾把 {{SAMPLE_RECORDS}} 条投放记录当成"{{SAMPLE_RECORDS}} 张图"，实际只有 {{SAMPLE_UNIQUE_IMAGES}} 张唯一图。**每次交付主动说明，别等对方问。**

## 结论写法

- 每条结论一句话 + 数据支撑，格式：`标签 / CTR / 对比基准 / 幅度`
  - 例：某类福利呈现的 CTR 高于无福利素材（填 `{{BASELINE_VALUE}}` 与 `{{BASELINE_LIFT_RANGE}}`，标注证据等级）
- 优先级分三级：**第一杠杆 > 次要因素 > 暂缓方向**
- 行动建议必须可执行：给"做什么 + 参考哪条素材 + 优先级"，并列出**暂缓清单**

## 缺口测算口径

```
月需求 = 投放天数 × 每日差异化张数（通常 2-3）
可复用 = 现有套数中历史验证高 CTR 的底稿数
净缺口 = 月需求 − 可复用
```
必须写明三条假设：①每日差异化张数 ②老底稿复用率 ③是否含版本换新缓冲。

## 对外输出脱敏对照（简历/分享必用）

| 内部数据（不要写） | 对外改写 |
| --- | --- |
| 曝光绝对值（如 1.68 亿） | "亿级曝光""近 10 个月全量投放数据" |
| CTR 点数值 | "约为大盘中位的 X 倍""进入平台前 5%"（用相对值，不写绝对值） |
| 分层 CTR 绝对值 | "老用户效率约为纯新进的 X 倍"（用倍数，不写绝对值） |
| 资源金额（X 万→4X 万） | "投放资源扩容约 4 倍" |
| 消耗/收入类 | 一律省略 |

原则：CTR 用**倍数/百分比差异/排名**；曝光与金额用**量级/倍数**；游戏名可写，平台内部指标口径不展开。
