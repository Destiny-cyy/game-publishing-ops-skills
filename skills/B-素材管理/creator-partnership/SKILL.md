# 创作者合作

借鉴 coreyhaines31/marketingskills 的 `influencer-marketing`（分层 / 合作模式谱系 / 披露 / ROI）。
**核心判断标准：影响力 = 信任 × 相关性，不是粉丝数。**
一个 {{BASELINE_VALUE}} 粉、观众全是 {{GAME_CN}} 玩家的攻略作者，胜过一个 {{BASELINE_VALUE}} 粉的泛游戏博主。

## 开工前

读 `_shared/context-template.md`（人群、产品线、口径）+ `../REDLINES.md`（创作者合作红线见该文件第二节）；准则层真源 `_shared/REDLINES.md` 第七章另有 KOC 相关红线（不代笔成官方口吻、只给事实边界）。
问清：目标（认知 / 转化 / 内容资产 / 信任）、预算（现金 or 虚拟物品）、平台、有无品牌安全红线。

## 两种常见创作者形态（不是传统 KOL 投放）

**形态一：{{CHANNEL_E}} KOC 内容矩阵**——每个节点发 10+ 篇资讯/攻略投稿。
历史表现须从当前项目数据源填写 `{{BASELINE_VALUE}}`，不得把其他项目的曝光、互动或评论区间直接作为本项目基线。
⚠️ **曝光与互动比悬殊**，说明泛资讯型投稿的转化价值有限。改进方向：每篇明确对应一个人群层（回归向/品类向/入库向），而不是统一发版本资讯。

**形态二：{{CHANNEL_TYPE_A}}自带 UP 主植入**——{{CHANNEL_C}} 等渠道在合作中打包 KOL 资源。
创作者数量、播放量和任务点击基线分别填写 `{{BASELINE_VALUE}}`，并标明来源、样本量和 `{{AS_OF_DATE}}`；示例不预置任何项目实测值。
**这部分是随渠道资源置换附带的，不单独付费——记得在方案里占用它，别浪费。**
⚠️ KOC 播放量与讨论量属**不可比口径**（准则 2.3）：分渠道单列，**严禁与{{CHANNEL_TYPE_A}}报的参与人数相加或横向比较**。要写进方案时标注"口径：播放/讨论量，非参与人数"。

对比参考：{{CHANNEL_TYPE_A}}单节点能带来 {{BASELINE_VALUE}} **参与人数**，而 一批 KOC 才做出 {{BASELINE_VALUE}} 讨论。
→ 内容渠道做声量与口碑，{{CHANNEL_TYPE_A}}做转化。预算分配应反映这个差异。

## 分层（按内容形态而非单纯粉丝量）

| 层 | 规模 | 特征 | 适合 |
|---|---|---|---|
| Nano | 1k–1万 | 互动率最高、超垂直 | 种子铺量、真实感 |
| Micro | 1万–10万 | 触达与信任平衡 | 主力转化层 |
| Mid | 10万–50万 | 广触达 | 认知层 |
| Macro | 50万+ | 顶部曝光 | 只在重大节点用 |

**{{GAME_CN}} 专项**：优先找本来就在做 {{GAME_CN}} 内容的创作者（攻略向 视频站r / {{COMMUNITY_VIDEO}} UP / 直播平台 主播）。
他们自带信任，且懂社区的雷区，能帮我们避坑。若 {{DEVELOPER}} 官方有创作者计划（{{GAME_CN}} Creator Program），先确认我们与该计划的关系再谈。

## 合作模式谱系（选模式，不选流行词）

- **付费赞助**：现金买曝光+信任借位，快
- **委托 UGC**：只买内容资产，不一定发布
- **寄送/赠送**：给虚拟物品或提前体验，无发布义务（适合 Nano/Micro 铺量）
- **联盟/分成**：按效果结算，需要先有追踪能力
- **大使计划**：长期关系，配合 `community-ops`
- **自然拥护者**：零成本，靠社区运营长出来

多数项目走组合：少量 Macro 打节点 + 一批 Micro 做转化 + 一个长期大使池。

## 选人核查（过不了就换人）

- 互动率而非粉丝数（异常低 = 买量号）
- 粉丝突增、机器人评论、互刷小队
- 过往争议内容
- **是否如实披露过往合作**
- 观众画像与我们的目标人群是否重合

## Brief 模板

```
合作背景：〔产品线/节点，一段话〕
必须传达（must-have）：〔2–3 条事实，逐条标注官方口径出处〕
不要碰（must-not）：〔红线，直接引 REDLINES.md〕
创作自由：〔明确说明哪些部分完全交给创作者，保留本人风格〕
形式与数量：〔平台 / 形态 / 条数 / 时长或字数〕
披露要求：〔平台规则 + 投放地区法规，必须显式〕
时间：〔提交构思 → 审核 → 发布窗口〕
回收：〔需要创作者提供的数据：48h 后台数据 + 原始素材 + 使用授权期〕
```

**写 brief 的原则**：给事实边界，不给逐字稿。创作者用自己的话说出来才有信任价值（红线 5）。

**给创作者的 brief 也要先脱敏**：内部基线（历史参与人数、加速环比、预算盘子）不出现在 brief 里——它与给渠道方的方案一样属于外发件（准则 10.3）。

### 内容分工：按人群层，不是统一发版本资讯

每篇 KOC 内容明确对应一个人群层（回归向 / 品类向 / 入库向），与 `content-brief` 的「人群 × 素材」表逐行对齐。统一发版本资讯是最低效的用法（曝光与互动比悬殊就是证据）。

## 回收指标（不要只看曝光）

有效回收 = 触达 → 互动质量（评论在讨论什么，而不只是点赞）→ 可归因的注册/回流 → 内容回声量（有没有被二次讨论、引用、二创）→ **负面声量占比**。

**硬纪律（准则 2.3 / 2.4）**：
- **曝光量、播放量、讨论量只作参考列，不作结案依据**，分渠道单列、**不得相加**。
- **声量类指标必须与负面声量一起看**，只报正面数据是自欺。
- 结案结论必须区分「归因明确」与「相关性推测」，不许把时间重合写成因果。
