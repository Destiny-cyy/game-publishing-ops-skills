# output/ — 分析结果与报告输出处（空目录）

**这里原本是空的，是故意的。**

这里可放使用方生成的洞察报告与人群事实 JSON。它们是**项目交付物**，不是方法，因此没有打进本包。

## 你会往这里放什么

| 命令 | 产出 |
|---|---|
| `python -m wfci.cli analyze` | 聚类结果 JSON（人群分群、关键词、规模、占比） |
| `python -m wfci.cli report` | HTML 洞察报告（一页看懂 → 运营决策总览 → 拉新/回流/留存拆解 → 数据附录） |
| `python -m wfci.cli export` | 机器可读「人群事实」JSON + 与场景档的 diff，供 `channel-plan` 选档用 |

## 三条规矩

1. **报告是运营决策工具，不是画像展示**：每个群体要给「核心需求 + 运营目标 + 打法建议」。
2. **人群事实只认原始聚类字段**（cluster / size / share_pct / top_keywords）；报告里的人群名与打法是模板生成的，仅供参考。
3. **重采后不自动回写场景档**：先看 diff → 人工确认 → 手动回写。旧值可能是上一期基线。

## 外发前

- 报告默认不含预算 / 权重 / 内部 KPI，别手动加。
- 对外 HTML 必须自包含（CSS 内联、图片内嵌、外部引用 0）。
- 引用人群结论时标注「样本口径 + 时点 + 证据等级」，声量不冒充人口。
