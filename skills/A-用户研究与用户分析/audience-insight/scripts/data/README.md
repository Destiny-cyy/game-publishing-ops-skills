# data/ — 采集原始数据存放处（空目录）

**这里原本是空的，是故意的。**

这里可放使用方自行采集的公开评论与帖子。这些内容涉及真实用户发言与平台数据，**不属于可迁移的方法**，因此没有打进本包。

## 你会往这里放什么

跑 `python -m wfci.cli collect` 之后，脚本会把结果写到这里，通常是：

| 文件 | 内容 |
|---|---|
| 视频社区评论 JSON | 公开视频的热评文本、点赞数、时间 |
| 论坛帖子 JSON | 公开帖子标题、正文、官方分类标签 |
| 游戏公开数据 JSON | 版本 / 活动摘要 / 新闻标题等获准公开接口返回 |

## 三条规矩

1. **只采公开可见内容**，遵守各平台条款与所在地法规。
2. **控制请求频率**（`REQUEST_INTERVAL` 别调太小），别用主力账号，别绕过登录态或反爬验证。
3. 这个目录里的数据**默认不外发**、不进版本库；报告里只给聚合结论与相对值，不给原始文本。

## 数据口径提醒

- 公开社区的**声量 ≠ 人口比例**：热评偏高赞、发帖人 ≠ 全体玩家。
- 对外引用必须标注「样本来源 + 口径 + 时点」，例如「视频社区评论 + 论坛帖子样本，声量口径，{{AS_OF_DATE}}」。
- 采集慢、分析快：**调参只重跑 analyze/report，别反复 collect**。
