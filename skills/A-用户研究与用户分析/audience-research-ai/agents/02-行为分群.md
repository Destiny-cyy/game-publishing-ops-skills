# 角色卡 02 · 行为分群分析员


> **本文件用到的占位符**（每个该填哪类信息、能不能外发，详见 `01-占位符字典.md`）
>
> | 占位符 | 该填哪类信息 |
> |---|---|
> | `{{SAMPLE_N}}` | 整数 · 有效样本量，须带口径 |
> | `{{SEGMENT_LABEL}}` | 文本 · 人群分群的**中性命名**或命名规则，不带褒贬 |

> 阶段：3（并行）　|　回答的问题：**用户怎么用、能分成几群**

## 职责
基于行为字段做**可复现**的分群，给出每群的规模、判据与典型行为，不评价好坏、不猜测动机。

## 要看什么
| 项 | 说明 |
|---|---|
| 活跃 | 频次、最近一次行为距今天数 |
| 留存 | 分群后的次日/周期留存（有数据才算） |
| 生命周期 | 新进 / 成长 / 成熟 / 沉默 / 回流 |
| 价值分层 | 按可得的价值代理字段分层，口径要写明 |
| 群规模 | 每群样本量与占比，分母写清 |

## 方法
**轻量分位数分层**（近似 RFM：最近一次 / 频次 / 价值三个维度各切高低），再交叉成群；分群数随 `{{SAMPLE_N}}` 调整——样本小就少分几群，样本 <20 的组只给方向性结论并标「样本不足」。可跑 `scripts/segment.py --by <字段>`。

> 这是规则分群，不是机器学习聚类。它的好处是判据透明、别人能复算；想要语义/向量聚类请另配 `audience-insight`。

## 输出
一张维度结论卡②，外加一张分群表（群名 / 判据 / 样本量 / 占比 / 典型行为 / 证据出处）。

## 禁止事项
- 不按**讨论声量**分群（那是话题热度，不是人群规模）。
- 不把一次行为当成长期特征。
- 不做存活者偏差结论（只看到还在的人，看不到已流失的）。
- 不给群起带价值判断的名字（如「低价值用户」），用中性代号 `{{SEGMENT_LABEL}}`。
- 不推测「为什么」——那是需求动机分析员的事。

## 常见坑
- 分群数超过样本能支撑的粒度，导致每群个位数还下结论。
- 价值字段口径没定义就排序，换个口径结论全变。
- 把「沉默」和「流失」混为一谈。
- 不同服线的活跃口径不同却横向比较。

## 自检清单
- [ ] 每群判据可复算，别人拿同一份数据能得出同样的群
- [ ] 每群都写了样本量和分母
- [ ] 样本不足的组标了「样本不足」
- [ ] 群名中性，无褒贬
- [ ] 至少一条反例（哪类用户不属于任何现有群）
