# 参考 03 · 数据入场检查表（四类数据 + 缺口声明）


> **本文件用到的占位符**（每个该填哪类信息、能不能外发，详见 `01-占位符字典.md`）
>
> | 占位符 | 该填哪类信息 |
> |---|---|
> | `{{ACTIVITY_WINDOW}}` | 文本 · 活动起止或持续天数 |
> | `{{AS_OF_DATE}}` | 文本 · 数据/资料的**时点**，格式 `YYYY-MM-DD`，引用时必带 |
> | `{{DATA_GAP}}` | 文本 · 明确声明**缺失的数据类别**及影响；**不许编数据补空** |
> | `{{NODE_TYPE}}` | **枚举**：`预约期` / `版本上线周` / `长线运营期` 三选一。它决定整套方法论走哪条分支 |
> | `{{SAMPLE_N}}` | 整数 · 有效样本量，须带口径 |

> 原则：**缺哪类就明写，不许 AI 用推测补齐**。
> 四类数据各自过一遍下面的检查项，全部登记进样本台账（表二）后才进入阶段 3。

## 统一记录格式

不管原来是什么格式，先统一成一条一条的标准记录（字段可按你的业务增减，但下面五个必填）：

| 字段 | 说明 | 必填 |
|---|---|---|
| `id` | 记录唯一标识 | ✅ |
| `source` | 数据来源类别 | ✅ |
| `text` | 原始文本（日志类可为事件描述） | ✅ |
| `user_tag` | 用户标识或匿名标签；用于去重，不要用真实身份信息 | ✅ |
| `timestamp` | 发生时点，带 `{{AS_OF_DATE}}` 口径 | ✅ |
| `extra` | 服线、设备、渠道、分群等附加字段 | 可选 |

`scripts/data_contract.py` 做的就是这件事：读 CSV → 校验必填 → 按 `user_tag + text` 去重 → 报缺口 → 输出统一 JSON。

**清洗三条硬规则**
1. **缺失单独计一类**，不要填 0、不要填「无」。
2. **去重口径写清**：是按记录去重、按用户去重，还是按内容去重？三个数不一样。
3. **口径不同的两份样本不合并统计**；要合并先换算到统一口径，换算不了就单列。

## 检查表 A · 评论 / 帖子

- [ ] 来源平台与时点已登记（`{{AS_OF_DATE}}`）
- [ ] 是公开可见内容，采集方式符合平台条款
- [ ] 标注了「讨论声量」口径，**没有**当成人口比例
- [ ] 说明高赞/热评偏差（这类样本天然偏向重度与情绪强的用户）
- [ ] 反讽、黑话、玩梗样本标记待人工复核
- [ ] 同一用户多条发言是否去重、按什么口径去重，已写明
- [ ] 服线/版块归属明确，没有把两条服线的内容混在一起

## 检查表 B · 问卷

- [ ] 问卷题目全文与选项已附（否则别人无法解释比例）
- [ ] 发放渠道、发放量、回收量、有效率分别登记
- [ ] 样本筛选条件写明（谁被排除了）
- [ ] 开放题与封闭题分开统计
- [ ] 有没有引导式提问？有的话该结论降一级证据
- [ ] 多选题占比之和可以 >100%，不要当错误处理，但要注明
- [ ] 未作答与「不知道/不适用」分开计

## 检查表 C · 访谈纪要

- [ ] 参与人数、招募方式、访谈时长已登记
- [ ] 是否录音/逐字稿，还是事后回忆纪要（后者证据等级降一级）
- [ ] 主持人提问稿已附（用于识别引导）
- [ ] 每条结论能挂到具体某位受访者的原话（匿名标签即可）
- [ ] 小样本明确标「方向性结论」，**不写占比数字**
- [ ] 访谈时的节点性质与 `{{NODE_TYPE}}` 一致

## 检查表 D · 行为日志

- [ ] 每个事件的口径定义（谁算、分母是什么）已附
- [ ] 埋点覆盖率：哪些动作能回传、哪些不能
- [ ] 时间窗口与 `{{ACTIVITY_WINDOW}}` 对齐
- [ ] 服线/平台字段完整；跨服线不合并统计
- [ ] 有没有把「点击」偷换成「完成」
- [ ] 存活者偏差：只看到还在的人，看不到已流失的，已注明
- [ ] 异常值/机器人流量是否剔除，规则已留痕

## 缺口声明模板（`{{DATA_GAP}}`）

每缺一类，照这个写，别只写「无数据」：

```
缺失类别：{{缺哪一类}}
影响哪些维度：{{列出维度编号}}
因此只能给到：方向性结论 / C 级假设 / 该维度不产出
替代证据：{{有没有其它来源可补，没有就写"无"}}
下期怎么补：{{一句话}}
```

**示例（虚构）**：
```
缺失类别：行为日志
影响哪些维度：② 行为分群、⑥ 旅程触点
因此只能给到：② 仅按问卷自报频次做方向性分群；⑥ 断点标"不可测算"
替代证据：访谈纪要里 3 位受访者提到过入口找不到
下期怎么补：与数据平台确认关键动作的埋点可行性后再采
```

## 样本量口径（三个数别混）

| 名称 | 含义 | 用在哪 |
|---|---|---|
| 原始记录数 | 清洗前行数 | 采集留痕 |
| `{{SAMPLE_N}}` | 清洗去重后的**有效样本量**，须注明是记录还是人 | 分析、报告 |
| 分群后各组样本量 | 每群的有效量 | 判断能不能下结论 |

> 样本 <20 的组只给方向性结论并标「样本不足」。分群数要跟着 `{{SAMPLE_N}}` 走，别把小样本切成十几群。
